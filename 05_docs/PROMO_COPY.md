# 可直接使用的宣传文案

## 标题备选

- RIFT：一台小车，更多可能
- 从全向移动开始，把你的想法装上车顶
- 绿色小车，可打印、可改造、继续一起做

项目暂用RIFT；软件名称仍为OmniCar。英文短名另可考虑MOSS、ROVE、SPROUT，尚未确定统一命名。

## 简短介绍

一台绿色的三轮全向小车，带着一点机甲感，也给改造留了空间。低矮车壳、磁吸电池盖、小巧取盖口，支持FDM打印；配套手机控制端、固件、模型与接线资料。下一步，我们想让同一台小车换上不同任务顶盖：小相机、轻型云台，或者你自己的模块。

## 项目发布正文

我们想做的不只是一台能跑的小车，也是一套能看懂、能打印、能继续修改的机器人项目。

三轮全向结构负责移动，手机控制端负责操控与校准。绿色外壳沿着底盘轮廓收紧，顶盖保持低矮；电池藏在盖下，小抠手位便于打开。内部与轮组沿用原结构，让外观升级和已有装配保持衔接。

顶部留给下一步的想法。复制一份顶盖，为自己的小相机、云台或传感器做专用安装座，让同一台底盘尝试不同任务。相机和云台图片是扩展构想，配件适配与承载测试还需要继续完成。

这次整理了STEP、STL、模型生成脚本、Android客户端、CyberBrick固件、接线图和运动学学习资料。欢迎从一次打印、一个配件、一条装配反馈开始参与。
