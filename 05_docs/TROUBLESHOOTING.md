# 故障排查

| 现象 | 优先检查 |
|---|---|
| 手机找不到RokiCar热点 | 确认已刷入新版固件，并检查板卡供电和固件启动 |
| 连Wi-Fi但APP不连 | 确认保留无互联网网络，地址192.168.4.1/ws，避免其它客户端同时占用 |
| 轮子只响不转 | 架空检查电源及机械阻力，重新标定最低起转PWM，不盲目加大电压 |
| 前进变旋转／斜走 | 检查W1/W2/W3映射与各轮方向，再校准增益 |
| 第三轮不动 | 核对D1/GPIO21、D2/GPIO20、DRV8833 VM/GND及模块使能脚 |
| 灯不亮／颜色不对 | 按作者确认的 D2 图核对 IN、供电、共地和模块型号；保持现有固件，不猜改灯脚 |
| 磁吸盖弹开 | 检查极性、孔内胶、间隙和电池线挤压；V8 已取消定位销 |
| 盖子抠不开 | 检查8毫米缺口与盖下净空是否被支撑/毛边堵塞；不可连固定壳边强撬 |
| 底盖与车壳有间隙 | 原参考装配定位存在偏移；先确认实物装配面/紧固关系，勿按渲染图推断尺寸 |
| 返航有偏差 | 实验功能无定位闭环，轮滑与速度误差会累积 |
