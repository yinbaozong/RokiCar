# 目前有哪些功能


以下按资料包内 **RokiCar Android 1.22.0 + 配套主固件** 整理；历史版本介绍中的旧功能不作为当前承诺。

| 功能 | 能做什么 | 使用说明 |
|---|---|---|
| 三轮全向混控 | 前进、后退、左右横移、斜向移动、原地旋转 | 先完成轮位与方向校准 |
| 手机摇杆控制 | 单摇杆、双控制、速度档位、旋转控制 | Android App 操作 |
| 横屏双手驾驶 | 两个摇杆配合控制，左右分区原地旋转 | 适合双拇指操控 |
| 手机姿态控制 | 通过倾斜手机控制移动 | 依赖手机传感器；手机航向跟随属于开环估算 |
| 电机标定 | 识别端口与轮位、修正正反转、设置最低稳定 PWM、调整轮速增益 | 先架空三轮再标定；可以保存配置 |
| RGB 灯光 | 开关、颜色与亮度调整，两盏前灯同步变化 | 需按当前灯控针脚连接 |
| 停车逻辑 | 急停；横屏按住运动、松手停车；退出或后台时发送停车；固件运动命令超时停车 | 当前固件命令超时阈值为 500 ms，首次装配需确认实际动作 |
| Wi-Fi 信号查看 | RSSI 实时曲线、数据年龄等信息 | 实际更新速度取决于手机 Wi-Fi 驱动 |
| 配置保存与查询 | 保存电机映射、方向与校准设置，查询灯光状态 | 固件与 App 需要配套 |
| 模型改造与学习 | STEP 模型、打印零件、运动学教程和模拟器 | 适合改外壳、做配件、学习混控 |

### 实验功能

**轨迹反放与 RSSI 辅助返航：** App 记录控制轨迹，再以反向顺序回放，并尝试结合 Wi-Fi 信号变化作局部修正。没有编码器或定位闭环，轮子打滑、地面差异和信号波动都会产生误差。这是一项可参与改进的实验功能，不能等同于可靠的自主返航。

**手机航向跟随：** 使用手机方位和虚拟车头估算控制转向；车体没有独立航向反馈，不能视为真正的无头模式或车载陀螺仪闭环。

当前 App 的 **AI 页面为待开发状态**。旧文档里的语音、云端 AI 和方形路径按钮不列为当前可用功能。摄像头图传、云台控制、视觉避障和自主导航也不属于基础版本。


# 欢迎把它变成你的 RokiCar


你可以从一台能玩的车开始：换一个颜色，拍一段横移视频，或者做一块自己的顶盖。进一步也可以优化灯光效果、改手机交互、完善接线教程，或让实验返航变得更可靠。

后续值得一起做的方向：

- 收集不同打印机、材料与磁铁的配合经验。
- 完善采购型号、插头针序、供电模块和逐针接线图。
- 做轻量、牢固、可重复拆装的相机扩展盖。
- 增加编码器或车载 IMU，改善轮速一致性与航向反馈。
- 研究图传、视觉功能和有定位反馈的导航。
- 改进 Android 兼容性，探索其他客户端。

如果你完成了复刻，欢迎展示你的版本，并附上打印材料、电机规格、软件版本和遇到的问题。能让下一位少走一步弯路的反馈，就已经很有价值。
