# 已有功能、实验功能与后续开发

以Android1.21和当前主固件为准；“源码已有”不代表本次完成实物验收。

| 类别 | 内容 | 状态 |
|---|---|---|
| 已有模型 | V7绿色车壳、磁吸电池盖、小抠手位、原底壳 | 用户确认V7；基础几何通过，试打待做 |
| 已有控制 | 三轮全向混控、前后左右平移、原地旋转、速度调节 | 源码已有，需正确轮位/方向标定 |
| 已有界面 | 单摇杆、双控制、横屏、手机姿态输入 | 当前App已有 |
| 已有校准 | 轮位、正反转、最低稳定PWM、速度增益 | 架空确认后保存 |
| 已有保护 | 急停、后台停车、连接中断/指令超时停车 | 代码已有，整车验证待用户执行 |
| 已有灯控 | RGB颜色、亮度、开关、状态查询与重试 | 1.20/1.21源码已有，实物输出待确认 |
| 实验 | 轨迹反放＋RSSI辅助返航 | 无定位闭环，不保证回到原点 |
| 实验 | 手机航向跟随/虚拟车头积分 | 无车载IMU反馈，打滑会积累误差 |
| 未开放 | AI语音与云端助手 | 1.21显示待开发，旧代码不等于启用 |
| 未开发验证 | 相机、云台专用顶盖和可靠锁止 | 当前仅扩展概念图 |
| 未开发 | 图传、视觉识别、自主导航 | 需要相机硬件及独立软硬件开发 |

## 优先级建议

1. 完成V7试打、磁铁配合、取盖手感与底壳真实合盖检查，发布实际装配照片。
2. 补稳压模块、灯模块与接头照片，完善逐项BOM和实测接线。
3. 复核灯控与急停/断连行为；记录电机标定结果和适用固件版本。
4. 为一个确定型号的小相机做专用盖与防脱固定，再测重心、振动与负载。
5. 做图传/云台控制；之后再评估IMU、编码器或视觉定位。
6. 改善实验返航；有反馈定位后再讨论自主导航。

可贡献方向：打印反馈、配件CAD、接线照片、文档、客户端兼容性、固件测试。当前不承诺速度、续航、载荷和定位精度。
