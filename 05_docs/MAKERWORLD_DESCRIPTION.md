# RIFT / OmniCar｜绿色三轮全向小车，顶盖可定制扩展

一台紧凑的绿色全向小车，配套FDM外壳、手机控制源码、CyberBrick固件与学习资料。

V7外壳保持原内部与轮组结构，低矮多边形电池盖采用磁吸固定，并留出小抠手位。车顶可以复制修改为专用扩展盖，为小相机、云台或传感器留出下一步空间。

## 下载内容

- V7 STEP、STL、原底壳与原整车参考STEP。
- 模型生成脚本、实际CAD爆炸图与抠手剖面。
- Android1.21源码及现有debug APK，CyberBrick主固件。
- 模块级电路连接图、逐线接线表、BOM、打印装配说明。
- 现有功能清单、实验功能说明与后续开发计划。

## 使用前说明

这是项目资料包，非全部零件一体打印模型。电机、轮组、控制板、电池和磁铁需要另备；清单见BOM。FDM参数是试打起点，没有针对特定打印机验证的3MF配置。

相机和云台图为扩展概念，不提供其支架CAD，不表示已实现图传或自动导航。返航为实验功能；AI页当前待开发。外观图是AI宣传图，制造以V7 STEP为准。
