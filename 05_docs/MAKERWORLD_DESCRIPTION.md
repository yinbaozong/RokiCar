# RokiCar 洛奇小车｜六边形三轮全向机器人

## 简介

RokiCar 是一台绿色的三轮全向小车。六边形车身配合黑色全向轮，支持平移与原地旋转；低矮磁吸顶盖便于电池检修，也给未来配件开发留出空间。

这个项目不仅提供外壳：资料包还包含Android控制器、CyberBrick固件、硬件接线、运动学教程与模拟器，方便理解、制作和继续改造。

## 当前版本特色

- 六边形绿色外壳，保留原内部、底盘接口与三轮运动结构。
- 独立磁吸顶盖，采用4颗直径8×厚2毫米磁铁。
- 小抠手位宽8毫米，盖下净空2毫米。
- 提供V7 STEP、STL、原底壳和原整车参考装配体。
- 提供手机控制、轮位/方向/PWM校准和RGB灯控源码。

## 制作说明

普通FDM打印，建议先打印磁铁孔试配块。0.4毫米喷嘴、0.2毫米层高、3–4圈外壁可作为试打起点，具体支撑和参数请按切片结果调整。本包未提供经过实机验证的3MF打印配置。

电机、轮组、电子板、电池和磁铁需要另备。当前BOM中有待实车确认的型号，不是完整采购套件。

## 功能边界

返航及开环航向估算属于实验功能；AI页当前待开发。相机磁吸一体盖、云台、图传与自主导航是后续方向，本次没有对应配件制造文件。

V7已完成基础CAD与STL检查，仍待试打和实车验证。整车封面是AI宣传效果图；爆炸图与取盖剖面来自实际模型。底盖实际配合以CAD和试装为准。
