# 名称与版本

- 项目名称：**RokiCar**，大小写固定。
- 中文昵称：**洛奇小车**。
- 说明用语：六边形三轮全向机器人。
- 当前机械：V8；当前Android：1.22.0。

项目、APP、热点、源码目录与当前文档统一使用 RokiCar。

热点SSID已改为 `RokiCar`，默认密码仍为 `12345678`，控制地址仍为 `ws://192.168.4.1/ws`。Android应用ID改为 `com.rokicar.controller`，所以1.22会作为独立APP安装。升级时必须同时刷入新版固件并连接新的RokiCar热点。

远程仓库目前私有；MakerWorld文案不把私有仓库当作用户下载入口。
