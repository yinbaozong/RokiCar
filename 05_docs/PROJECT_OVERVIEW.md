# 项目总览

## 项目定位

这是一个基于 CyberBrick 的三轮全向移动小车项目。三只轮子的组合速度实现平移和原地旋转，手机通过小车Wi-Fi进行控制。绿色外壳、黑色轮组、低矮多边形顶盖形成统一外观；可更换顶盖作为未来相机、轻型云台或小模块的开发入口。

## 系统构成

| 模块 | 工作区实际提供 | 状态与边界 |
|---|---|---|
| 机械 | 原整车装配体、底壳、V7新车壳与盖 | 内部与轮位不改；V7由用户确认外观，待试打 |
| 供电 | STEP中的14500、7.4V、800mAh电池 | 用户确认位置尺寸与实车一致；电池线通向内部 |
| 控制 | CyberBrick接收板M1/M2＋一块DRV8833 | 当前主方案；另保留双DRV8833旧方案 |
| 固件 | MicroPython boot.py、main.py、omni_core.py | Wi-Fi热点、WebSocket、电机混控、校准、灯光、超时停车 |
| 手机端 | 原生Android 1.21.0 | 摇杆、横屏操控、手机姿态控制、校准、灯控；真机效果以实测为准 |
| 实验功能 | 轨迹反放与Wi-Fi RSSI辅助返航 | 无位置闭环，不能宣传为可靠自主返航 |
| AI页面 | 当前1.21仅待开发提示 | 旧记录中语音/云端方案不等于现版本已启用 |
| 学习 | 逆运动学教程、HTML运动模拟器、接线SVG | 用来理解轮位、方向、速度混合 |
| 扩展 | 可定制顶盖，相机/云台效果图 | 支架、孔位、电气接入、承重尚未开发验证 |

## 主要结构参数

- 原车壳平顶Z=35 mm，新盖顶Z=38.5 mm；相对原顶面增加3.5 mm。
- 独立盖子约64×51×3.3 mm；外壳打印网格包围盒约95.26×104.12×37.7 mm。这些不是整车含轮外形尺寸。
- 4颗直径8 mm、厚2 mm磁铁，组成两对。孔径8.25 mm、深2.15 mm。
- 单侧抠手位宽8 mm；盖下净空2 mm；盖唇厚2.2 mm，原外顶面局部下沉0.7 mm。
- 内部、电池开口与轮子运动机构保留；外部不新增电池出线口。

## 已完成与后续

已完成：V7车壳/盖、打印导出、取盖剖面、基础几何检查、工作区软件归档、宣传图与文案。
后续建议：试打磁铁块→车壳/盖配合→实际取盖与行驶检查→按具体相机尺寸设计扩展盖→验证固定、供电与重心。

未提供续航、速度、有效载荷、爬坡或防水等级的实测数据，因此不设定这些宣传指标。
