# V7 制造与装配

## 文件与材料

`01_shell_print.stl` 为新车壳，`02_hatch_print.stl` 为盖子，`04_magnet_fit_coupon.stl` 为磁铁孔试配块。单位毫米。原底壳以STEP提供，可在CAD或切片软件中转换；未改原结构。

可用普通FDM打印。0.4 mm喷嘴、0.2 mm层高、3–4圈外壁可作为起始设置，并非已实测的唯一参数。磁铁孔先试打，避免一次打印整壳后才发现孔径不合。

盖子STL已翻转为外顶面朝下，侧面小缺口朝向切片结果核对。车壳STL底部落在Z=0；因保留原内部结构，需在切片器检查内部顶面、桥接和支撑可移除性，不承诺无支撑打印。根据材料与机器误差调整孔隙。

## 磁铁

使用直径8×厚2 mm磁铁，共4颗。直径2×厚4 mm磁铁不适配当前版本。壳和盖各有两处盲孔，先不点胶，确认极性成对相吸，再固定；避免胶溢到接合面。

## 组装顺序

1. 保留原底壳、轮组和内部零件，按原装配关系更换外壳。
2. 对照STEP放入原电池，导线仍通向内部，不增加外部线孔。
3. 检查盖子定位销/孔，轻放顶盖并确认四周能贴合。
4. 从单侧小缺口把指甲伸到盖子下方，上提盖唇。缺口处固定围边已经让开。
5. 架空检查轮子全周转动与线束，随后低速测试。

## 验证边界

CAD确认盖子与车壳无实体重叠、电池向上取出路径无新增阻挡；指甲通道采用4 mm宽、1.2 mm厚的几何包络检查。STL均为单一封闭实体，体积为正。报告见 `01_model/docs/`。这些检查不等于实际手感、磁吸强度或机械寿命测试。

## 修改模型

`01_model/source/build_model.py` 从原壳STEP生成当前外观，使用Python与CadQuery。已使用的环境为Python3.13、CadQuery2.8.0。运行会重建cad/print/build产物，请在副本中修改。渲染脚本还使用numpy/Pillow，剖面图使用trimesh/matplotlib。STEP能导入SolidWorks；没有原生SolidWorks特征树。
