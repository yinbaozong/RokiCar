# 快速开始

1. 阅读BOM和硬件连接表。没有现有实车时，先确认电机、轮组、板卡和供电型号；本包不是完整已核实采购套件。
2. 用`04_magnet_fit_coupon.stl`试配直径8毫米、厚2毫米磁铁；整车需要4颗。
3. 切片新车壳与顶盖。盖子STL已外顶面朝下；车壳保留原内部结构，检查支撑可移除性。
4. 按原装配保留内部和轮组，替换外壳，检查原底盖定位；电池线保持向内走线。
5. 主固件为boot.py、main.py、rokicar_core.py。刷写方法结合所用CyberBrick配置指南；本次未对实车执行刷机。
6. 安装 `RokiCar-Controller-v1.22-debug.apk`，刷入新版固件后连接热点 `RokiCar`。默认密码为 `12345678`。
7. 将三轮架空，完成轮位、正反转、最低稳定PWM和速度增益校准。先单轮再联动。
8. 确認松手、急停、断线停车，随后落地低速测试。实验返航暂不作为首次测试目标。

完整操作与注意点见打印装配、软件、硬件文档。相机顶盖尚未提供制造文件，不要按宣传想象在装有电池的顶盖上盲钻。
