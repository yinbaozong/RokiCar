# 给顶部更多可能


![相机搭载实拍优化](../04_media/02_camera_real.png)

实拍中已经展示了搭载小型相机的形态。它可以成为移动拍摄底盘，也可以成为研究相机支架、传感器与扩展顶盖的起点。

可拆卸顶盖适合作为独立改件：先在 STEP 副本上设计安装孔、转接支架或加强筋，确认不会碰到电池与内部线束，再打印专用盖子。相机属于额外配件，照片中的相机不在基础采购清单里；当前 App 未集成图传或云台控制，也尚未交付已验证的磁吸相机支架。

想做机械扩展，可以尝试轻型相机底座、可替换饰板或传感器盖；想做软件扩展，可以尝试编码器反馈、车载 IMU、闭环轮速、定位与视觉处理。相机固定、重心变化和顶盖承载应在自己的配件方案中实测。
