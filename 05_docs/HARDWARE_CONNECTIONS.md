# 当前硬件连接总表

依据包内当前main.py、接收板M1/M2方案和App1.20灯光说明整理。参见 `03_hardware_and_learning/当前主线连接总图.svg`；旧双DRV8833图属于备选，不与主线混接。

| 起点 | 终点 | 用途 |
|---|---|---|
| 接收板M1电机口 | W1左前电机两线 | 板内GPIO4/5控制，不要求额外焊线 |
| 接收板M2电机口 | W2右前电机两线 | 板内GPIO6/7控制 |
| D1信号/GPIO21 | 外接DRV8833 AIN1 | 第三轮方向/PWM |
| D2信号/GPIO20 | 外接DRV8833 AIN2 | 第三轮方向/PWM |
| DRV8833 AO1/AO2 | W3后电机两线 | 电机输出 |
| 电机稳压电源正极 | DRV8833 VM | 原方案为6V；按实车电机额定值核对 |
| 接收板GND、电源负极 | DRV8833 GND | 共地 |
| DRV8833使能/休眠端（若引出） | 按具体模块接有效使能电平 | 老资料写STBY，部分模块丝印为nSLEEP；不能当成统一针脚定义 |
| S1信号/GPIO3 | 灯控模块IN | 当前CN301方案；D1/D2已占用 |
| 稳压5V与GND | 灯模块电源 | 核对实物输入要求；固件驱动4个像素输出同色 |
| 电池正极→原主开关 | 原供电/稳压模块输入 | 电池标称7.4V，并非全部器件都能直接接7.4V |
| 原板卡供电支路 | CyberBrick供电输入 | 保持原板卡要求；现有资料未明确具体稳压器型号 |

DRV8833的B路在当前主方案中不用。电机正反转不能只靠线色确定，须在App架空校准。所有电源共地；接收板小信号口不能代替电机电源。

## 电路资料的完整程度

本包提供模块级连接图、逐线连接表和现有接线SVG，没有自制PCB原理图/PCB/Gerber。工作区没有完整的自研板级电路设计文件，因此不虚构。开关型号、稳压模块具体型号、灯模块接头序和部分紧固件尚需补实车资料。

## 首次通电与软件匹配

先核对极性与各路输出电压，轮子架空。使用主固件目录boot.py/main.py/rokicar_core.py与Android1.21。先单轮测试，再轮位/方向/起转/增益校准，最后低速运行。灯色和首次连接状态仍需真机检查。
