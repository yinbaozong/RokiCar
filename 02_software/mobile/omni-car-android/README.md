# OmniCar Android

## 1.21.0

- 灯控首次连接自动补发状态查询（750ms 间隔，最多 10 次），不再依赖一次回复。
- 最新灯光命令未确认时每 500ms 重试，最多发送 4 次；旧状态不会覆盖最新操作，断线取消待发命令。
- AI 页只显示“待开发中”，关闭原生语音监听；返航顶部标注“实验功能”。
- 移除设置页闭环方形路径按钮及其事件处理。
- 使用 1.20 核心板程序，无需重新刷机。连接恢复、确认重试和断线取消三项模拟测试通过，仍需真机确认首次开灯效果。

## 1.20.0

- 设置页新增 RGB 灯光开关、颜色及亮度；两个灯同步变化。
- 需要同步上传 `firmware/cyberbrick_omni_m1m2_plus_drv8833/main.py`。
- CN301 IN 信号接 S1 / GPIO3，正极接稳压 5V，负极共地；D1/D2 仍用于第三电机。
- 协议类型 12，三个 int16 字段为 R/G/B（0–255）；全零关闭。四个输出统一设色，开机默认关闭。
- 灯控不更新运动超时计时；断线重连只读取灯状态，不重放开灯命令。
- 软件验证通过后仍需连接实物验证 CN301 输出和颜色顺序。

## 1.19.0

- Wi-Fi RSSI 保持每 `50ms` 读取和绘图，即 20Hz 界面刷新。
- 返航页新增读取频率、数值变化频率和数据年龄；原始值保持整数，平滑曲线显示一位小数。
- 灰线显示原始 RSSI，绿线显示滤波结果；返航趋势只接收真正发生变化的读数，避免重复缓存值被当成新证据。

## 1.18.0

- 横屏控制改为两只清晰的圆形摇杆，并显式绘制摇杆头，修复真机只显示轨道的问题。
- 左摇杆限定纵向油门，右摇杆限定横向转向；底部原地旋转按钮保持左右分区。

## 1.17.0

- 横屏双控制改为两个连续滑块：左侧纵向油门，右侧横向转向，支持双拇指同时拖动。
- 删除横屏四方向按键；原地左转和右转改为底部左右分区，退出键单独置顶。

## 1.16.0

- 横屏驾驶改为拇指分区：移动键固定贴近左侧，原地旋转和退出固定贴近右侧。
- 陀螺仪启动后自动开启平移，不再显示平移开关、姿态模拟和手动握姿校准。
- 航向转向独立切换：开启时只旋转，关闭后立即恢复前后左右平移。
- 返航终点 RSSI 默认修正为 `-35 dBm`，并修复首次启动被错误设成 `-20 dBm` 的问题。

## 1.15.0

- 双控制新增独立横屏驾驶界面：前进、后退、左移、右移、原地左转、原地右转和退出。
- 横屏控制按住才运动，松手、取消触摸、退出、后台和急停都会停车。
- 普通页面改为原生纵向滚动，横屏控制不再与页面滚动争夺手势。

## 1.13.0

- 陀螺仪模式新增手机航向跟随：校准时记录手机方位，左右旋转手机会让小车转向。
- 使用手机目标角度、虚拟车头积分和比例减速控制，误差进入 4° 死区后停止旋转。
- 航向数据超过 500ms 未更新时立即清零旋转命令。
- 这是无车载 IMU 的开环估算；轮胎打滑后可点“校准握姿”重新归零。

## 1.12.0

- “倾斜”模式改名为“陀螺仪”，固定输出纯平移与 `ROT=0`。
- 双控制转向上限由 27% 提升到 35%。
- 返航终点 RSSI 可手动设置，并显示最近约 60 秒实时曲线。
- RSSI 读取请求提升到 50ms；实际更新频率仍由 Android Wi-Fi 驱动决定。
- AI 页增加实时语音识别文字，并提示 OmniCar 无互联网时需要开启移动数据。

真正的无头模式需要车载 IMU 或其他车体航向反馈。当前手机传感器只能控制平移方向，无法测量车体因轮差产生的偏航。

## 1.11.0 测试版

安装包：`E:\三轮小车-麦克纳姆林\OmniCar-Controller-v1.11-debug.apk`

手机连接 `OmniCar` Wi-Fi 后打开 App。底部页面分为操控、AI、返航、设置与校准。

首次升级必须先把三只轮架空至少 10mm，然后在“设置与校准 > 完整电机标定向导”依次完成：

1. 点 M1、M2、外接板，确认它们对应 W1 左前、W2 右前、W3 后轮。
2. 观察每轮实际方向并选择“与图一致/相反”。当前故障现象高度提示 W3 需要反向，但请以实车观察为准。
3. 对每个物理端口运行 PWM 递增，连续稳定转动时点“已稳定”。
4. 架空预览前进、右移、原地右转，全部正确后保存。
5. 再运行三轮各五秒计圈，计算并保存速度增益。

方形测试现在按前进、右移、后退、左移执行，每边 5 秒、间隔 250ms，所有段 `ROT=0`。返航以反向轨迹为主，达到自适应 RSSI 目标立即停车；RSSI 连续恶化至少 3dB 时暂停并做四方向局部测向。

AI 语音配置只需一个阿里云百炼 API Key，模型为 `paraformer-realtime-v2`；DeepSeek Key 单独填写。心形、三角形、方形和五角星由 App 本地生成，执行前必须预览确认，并要求先完成距离标定。

原生 Android 控制器，直接连接 CyberBrick 的 `ws://192.168.4.1/ws`。不依赖 DCloud，项目可直接用 Android Studio 打开。

## 安装包

当前版本：`1.10.0`

```text
E:\三轮小车-麦克纳姆林\OmniCar-Controller-v1.10-debug.apk
```

USB 调试安装：

```powershell
adb install -r "E:\三轮小车-麦克纳姆林\OmniCar-Controller-v1.10-debug.apk"
```

手机先连接 `OmniCar` Wi-Fi，再打开 App。界面底部有四个分栏：

- `操控`：单摇杆、双控制、手机倾斜、速度档位和原地旋转。
- `AI 助手`：本地唤醒词“小麦小麦”、多轮对话记录、文字指令及云端配置。
- `返航`：轨迹回放、Wi-Fi 辅助判断、方形路径和距离标定。
- `设置`：重新连接和三轮五秒计圈校准。

红色方形按钮是全局急停，切换任何分栏也会先停车。

返航会从第一次移动开始持续保存最多十分钟的控制轨迹，App 重启后仍可恢复。返回时先按原速度、反序执行尚未回放的轨迹，并逐段删除已完成部分；只有回放后的信号明显弱于出发点基线，才用四方向 Wi-Fi 试探作局部修正。Wi-Fi RSSI 只能辅助判断远近，不能提供绝对方向。

闭环方形测试位于 `设置`，按前进、右移、后退、左移运行，每边 3.5 秒，理论终点为起点。没有编码器或视觉定位时，落地误差仍需通过轮速校准降低，软件无法测得真实厘米级位置。

## 小麦语音

语音链路为：本地 `sherpa-onnx` 唤醒词检测 → 阿里云一句话识别 → DeepSeek 受限工具决策 → App 校验动作 → CyberBrick 执行 → Android TTS 回复。

1. 在 `AI 助手 > AI 云端配置` 填写阿里云 AppKey 和临时 Token。
2. 填写 DeepSeek API Key。未填写时只支持本地基础移动指令。
3. 点击“安全保存到本机”，再开启“小麦小麦”监听并允许麦克风权限。
4. 连续说“小麦小麦”，听到“我在”后再说完整要求。

密钥使用 Android Keystore 加密保存，不写入 APK。阿里云临时 Token 过期后需要重新填写。DeepSeek 只能选择受限的移动、旋转、停车和返航工具，单次运动最长五秒，不能直接生成 PWM 或 GPIO 指令。
