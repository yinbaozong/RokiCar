# OmniCar Android 控制器

这是三轮全向小车的 Vue 2 UniApp 原生 Android 控制端。它直接连接 CyberBrick 热点，不依赖互联网，也不会修改参考工程。

## 导入和运行

1. 手机连接 WiFi `OmniCar`，密码 `12345678`，允许系统继续使用“无互联网”的网络。
2. 在 HBuilderX 中选择“文件 -> 导入 -> 从本地目录导入”，选择本目录。
3. 打开 Android 手机的开发者选项和 USB 调试。
4. 在 HBuilderX 中选择“运行 -> 运行到手机或模拟器 -> 运行到 Android App 基座”。
5. App 会连接 `ws://192.168.4.1/ws`。顶部显示“已连接”后再操作。

正式 APK 需要可用的 DCloud 打包环境或账号。当前电脑没有安装 HBuilderX，因此工程已准备到可直接导入的状态，但尚未生成 APK。

## 四种控制方式

- **方向键**：按住前后左右平移；下方按钮原地左右旋转。
- **单摇杆**：方向决定平移方向，离中心越远越快；下方按钮控制旋转。
- **双摇杆**：左侧平移，右侧横轴旋转，可边走边转。
- **手机倾斜**：先以当前握持姿态校准，前后左右倾斜控制平移，下方按钮控制旋转。

慢速、标准、快速分别是 `35%`、`55%`、`75%`。所有方向都相对车头箭头，不是无头模式；核心板仍用 `SPEED_LIMIT=0.45` 做最终限速。

## 倾斜安全

- 启动后先采集约 `500ms` 作为当前水平零点。
- `3°` 内为死区，`3°` 到 `25°` 连续映射速度，超过 `25°` 保持当前档位上限。
- 加速度数据超过 `300ms` 未更新、相对倾角超过 `40°` 或加速度异常时立即解除并停车。
- 切换模式或速度、App 进入后台、锁屏、断网、WebSocket 断开时停车。
- 重连只恢复通信，绝不自动恢复运动或倾斜状态。

手机安装到车上时不要启用倾斜遥控。本版本只支持一个控制端，不支持车载手机和另一台遥控手机同时控制。

## 逻辑测试

电脑安装 Node.js 后在本目录运行：

```powershell
npm test
```

测试覆盖倾角计算、校准、死区、滤波、限幅、传感器超时和 12 字节二进制协议。
