# CyberBrick 接收板 M1/M2 + 一块 DRV8833 接线方案

## 1.11 固件新增

- 协议 `9`：按物理端口和真实 PWM 测试单轮。
- 协议 `10`：设置三轮最低稳定起转 PWM。
- 协议 `11`：查询轮位、方向、增益和起转值。
- 非零轮速采用“起转 PWM + 有效区间线性映射”，改善 N100 低速只响不转。
- 方形测试接受每边最长 5000ms，固定平移且 `ROT=0`。

升级后请使用 Android App 1.11 的完整向导重新确认轮位、方向和起转值。不要只根据接线推断 W3 正反方向。

这个方案不用从核心板 GPIO20/GPIO21 焊线。

官方源码里：

```python
LED_CHANNEL1 = 21
LED_CHANNEL2 = 20
```

所以接收板上的 LED 接口可以拿来当普通 GPIO 使用：

```text
D1 LED 口信号脚 = GPIO21
D2 LED 口信号脚 = GPIO20
```

## 电机分配

| 轮子 | 接法 |
|---|---|
| W1 左前轮 | 接收板 M1 |
| W2 右前轮 | 接收板 M2 |
| W3 后轮 | 外接 DRV8833 的 A 路 |

## 外接 DRV8833 接线

| DRV8833 | 接哪里 |
|---|---|
| VM | 6V 电机电源正极 |
| GND | 6V 电源负极 + 接收板 GND |
| STBY | D1/D2/舵机口的 V，或核心板 3V3 |
| AIN1 | D1 LED 口的信号脚，也就是 GPIO21 |
| AIN2 | D2 LED 口的信号脚，也就是 GPIO20 |
| AO1 / AO2 | W3 后轮电机两根线 |
| BIN1 / BIN2 | 不接 |
| BO1 / BO2 | 不接 |

注意：D1/D2 口的 V 只能用来拉高 STBY，不能当电机电源。DRV8833 的 VM 必须接 6V 电机电源。

## D1/D2 三针怎么认

看接收板丝印，LED 口通常是：

```text
D / V / G
```

或类似顺序。

你只需要：

```text
D1 的 D -> DRV8833 AIN1
D2 的 D -> DRV8833 AIN2
任意 G -> DRV8833 GND
V -> DRV8833 STBY
```

如果不确定哪根是 D，用万用表或拍近一点的丝印图再确认。

## App 通信

1.11 起移除板载控制网页。手机连接 `RokiCar` 后使用 Android App，App 直接连接 `ws://192.168.4.1/ws`。固件保留 `/health` 诊断接口，其他 HTTP 地址返回 `404 app_only`。

App 切到后台或 WebSocket 断开时会清空运动状态；核心板超过 `500ms` 没有收到运动指令也会自动停车。
