# RokiCar V8｜取消定位销、单组磁吸与围边加厚

本版从 RIFT-V7 的原始车壳重建，原 V7 文件保留，输出在 `外壳设计/RokiCar-V8`。

## 本次修改

- 取消车壳两颗 Ø1.6 mm 定位销，顶盖对应的两处孔也取消。
- 顶盖只保留后侧 **一颗 Ø8×2 mm 磁铁**；车壳同一位置一颗配对。总共两颗磁铁、一个磁吸位置，前侧另一组孔不再生成。
- 围边改为 **1.6 mm 连续竖直壁**，高度为车顶以上 2.4 mm；保留取盖缺口。
- 取消原来的围边裁切方式，避免后侧斜边被原车顶轮廓裁成薄片。超出原车顶的少量围边用外侧斜面过渡支撑，过渡高度 3.2 mm、横向扩张 1.6 mm。
- 不移动内部安装结构、底壳或三轮机构。

## 配合尺寸

| 位置 | 设计尺寸 |
|---|---:|
| 盖子与围边横向间隙 | **每侧 0.40 mm**，相对两侧合计 0.80 mm |
| 模型中盖子底面与原车顶的轴向间隙 | 0.20 mm |
| 适配磁铁 | Ø8×2 mm |
| 车壳、顶盖磁铁孔 | **Ø8.40 mm × 深 2.10 mm** |
| 磁铁孔直径余量 | 0.40 mm，即径向每侧 0.20 mm |
| 磁铁孔深度余量 | 0.10 mm |
| 顶盖磁铁孔上方剩余材料 | 1.20 mm |
| 原车顶磁铁孔底及周边已核对的材料余量 | 至少 1.0 mm |

这些是用于普通 FDM 的设计余量，不是打印机的尺寸精度保证。磁铁孔按留胶间隙设计；先用试配块核对自己的磁铁与打印结果，不建议靠强行压入固定。

## 文件

- `cad/01_shell.step`：无定位销、单磁铁孔的新车壳。
- `cad/02_hatch.step`：无定位孔、单磁铁孔的顶盖。
- `cad/03_shell_assembly.step`：车壳与顶盖的装配位置参考。
- `print/01_shell_print.stl`：车壳打印文件。
- `print/02_hatch_print.stl`：顶盖打印文件，外顶面朝下。
- `print/04_magnet_fit_coupon.stl`：磁铁孔试配块。
- `docs/cad_checks.json`：几何核对数据。
- `docs/mesh_checks.json`：打印网格核对数据。

## 核对与下一步

已完成建模时的零件有效性、单实体、盖壳无实体重叠、电池取出路径、抠手通道、外侧过渡不侵入原内部、原车壳无非预期切除，以及多高度围边材料核对。打印网格检查另记于 `mesh_checks.json`。

尚未替你切片或实物试打。请优先查看你圈出的薄边能否形成连续路径，再确认盖子间隙和单组磁吸的手感。主发布文档与宣传封面仍为上一版，这次先交付修改模型供你确认。
